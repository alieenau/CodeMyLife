Code My Life

Belajar Python lewat rutinitas sehari-hari

Tulis skripnya, biarkan karaktermu menyelesaikan rutinitas!

Fitur Utama

Python sungguhan

Tulis loop, kondisi, dan fungsi di editor. Jalankan gratis untuk mencoba, Kirim untuk menguji.

Botu dan baterai

Botu menjalankan skripmu. Tiap langkah memakai baterai, jadi kode yang hemat lebih baik.

Situasi uji

Kirim mencoba kodemu di beberapa situasi (letak benda berubah), jadi tidak cuma cocok untuk satu contoh.

Error yang membantu

Baris yang salah disorot dan dijelaskan penyebabnya. Tidak ada Game Over.

Bintang 1 sampai 3

1 = lulus. 2 = lulus di semua situasi. 3 = juga singkat dan hemat. Hint tidak mengurangi bintang.

Hari Kritis

Level penutup tiap babak, dengan jam game dan tenggat waktu. Progresmu tersimpan di browser.

Peta Babak

Lulus dengan 1 bintang untuk membuka level berikutnya. Babak baru terbuka setelah babak sebelumnya selesai.

Prototipe: kodemu dijalankan oleh interpreter Python-mini (for, while, if/elif/else, def, list). Versi penuh memakai Python asli.
